# 2023_ds

## PROCEDURAL — 芸術工学部 小倉悠悟

`index.html` は、同心円・放射する文字列・縞で組んだ字形が止まらずに流れ続けるプロシージャル・パターンのサイトです。外部ライブラリなし、Canvas 2D の単一ファイルで動きます。

### 操作

| 入力 | 動作 |
| --- | --- |
| クリック / タップ / `R` | 模様を再生成 |
| `S` | 現在のフレームを PNG 保存 |
| `Space` | 一時停止 |
| `I` | 白黒反転 |
| マウス移動 | 同心円の中心がわずかに追従 |

12 秒ごとに乱数種が変わり、グリッチを挟んで次の構図に切り替わります。`prefers-reduced-motion` が有効な環境では速度を落とし、グリッチを止めます。

### 文言の変更

`index.html` 冒頭の `CFG`（学部名・氏名・ローマ字表記・声明文・詩）を書き換えると全体に反映されます。

### GitHub Pages で公開

1. このブランチを `main` にマージする
2. リポジトリの **Settings → Pages** で Source を **Deploy from a branch**、Branch を `main` / `(root)` にする
3. `https://<ユーザー名>.github.io/2023_ds/` で公開される

`Webapp.html` は以前の和柄ジェネレーター（そのまま残しています）。
